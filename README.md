## 줄거리

3월 둘째 주 월요일, 4번 출구 계단.
흩어진 전단지를 줍느냐, 벤치의 선배에게 인사하느냐, 아니면 이어폰을 끼느냐.
그 작은 선택 하나가 닷새의 방향을 바꾼다.

## 플레이 방법

- **화면 클릭 / Space / Enter** — 대사 진행 (출력 중이면 즉시 전체 표시)
- **선택지** — 번호 버튼 또는 화면의 선택지 터치
- **로그** — 지나간 대사 다시 보기
- **저장 / 로드** — 슬롯 3개 + 자동 저장 (브라우저 `localStorage`)
- **설정** — 텍스트 속도(느리게 / 보통 / 빠르게 / 즉시), 효과음 켜기·끄기
- 모바일(iPhone) 세로 화면에 맞춰 반응형으로 동작합니다.

## 엔딩

선택과 호감도에 따라 **4종**의 엔딩이 있습니다. 타이틀 화면의 「엔딩 도감」에서 수집 현황을 볼 수 있습니다.

## 구성

```
index.html            무대 · 타이틀 · 모달 마크업
css/style.css         4레이어 무대, 대사창, 선택지, 반응형
src/engine.js         엔진: 타자기·분기·호감도·세이브·WebAudio
src/data/scenario.json 시나리오 175노드 (대사 · 선택지 · 분기 · 엔딩)
assets/img/           배경 3종 · 캐릭터 스탠딩 8종 (WebP)
tools/mobile-preview.html  데스크톱에서 아이폰 크기로 확인하는 미리보기 페이지
```

- 무대는 배경(크로스페이드 2겹) → 캐릭터(표정 전환) → 이펙트(꽃잎·비네트) → UI(대사창·선택지) 4레이어로 구성됩니다.
- 효과음은 WebAudio로 실시간 합성하며 외부 오디오 파일이 없습니다.
- 캐릭터 표정은 기본 이미지에서 표정만 바꿔 생성해 인물의 일관성을 유지했습니다.
